# NZA Website — design briefs

These are the source briefs from the Claude Design handoff bundle. They travel with the repo so future contributors and AI agents can read the spec at the same place they read the code.

| File | Purpose |
|---|---|
| `design-system.md` | **The spec of record.** Locked v2 design system: voice rules, type, colour, spacing, layout, motion, per-screen requirements. Originally `uploads/nza-design-system.md` in the Claude Design bundle. |
| `handoff.md` | What's built and what's open in the Claude Design prototype, plus the v1 → v2 deltas (why decisions were made). |
| `brief.md` | Brand strategy and positioning brief. Why NZA, who the audience is, what the site needs to do. |
| `source-bundle-readme.md` | Original README from the Claude Design bundle — content fundamentals, voice, visual foundations, iconography. |

When porting a screen, read `design-system.md` first, then the relevant section of the prototype HTML/CSS in the source bundle (path noted in `CLAUDE.md`).
